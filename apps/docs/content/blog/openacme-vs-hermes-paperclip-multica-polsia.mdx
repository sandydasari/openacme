"AI workforce" went from a tagline to a category in 2026. A handful of platforms
now let you run more than one agent, hand them tasks, and walk away. They are not
the same product, though — some run a single agent that grows with you, some
orchestrate coding CLIs you already use, one is a closed SaaS that takes a cut of
your revenue, and OpenAcme runs a local-first roster of agents on your own
machine.

This post lays them out side by side. Where we state a fact about another
project, it's drawn from that project's public README, site, or press coverage
and linked. Where we give an opinion, we say so. The goal is a comparison you can
actually trust — not a strawman.

## What each one actually is

### Hermes Agent (Nous Research)

[Hermes Agent](https://github.com/nousresearch/hermes-agent) is MIT-licensed,
Python, and one of the most-starred agent projects on GitHub. Its pitch is "the
agent that grows with you": a **single** agent with a built-in learning loop that
creates skills from experience, curates its own memory, and models who you are
across sessions. It lives across channels — Telegram, Discord, Slack, WhatsApp,
Signal, CLI — and runs on a $5 VPS or serverless infra.

**How OpenAcme differs:** Hermes is depth on *one* agent; OpenAcme is breadth
across *many*. If you want a single, deeply personalized assistant that
follows you everywhere, Hermes is excellent. If you want a roster of
role-specialized coworkers — a PM, a frontend dev, a marketer — that assign tasks
to each other on a shared board, that's the shape OpenAcme is built around. Hermes
can spawn subagents; OpenAcme treats the multi-agent org chart as the primary
object, with per-agent memory, tools, browser, and model.

### Paperclip

[Paperclip](https://github.com/paperclipai/paperclip) is the closest competitor
in spirit — MIT, self-hosted, and explicitly about running a *company* of agents
with org charts, budgets, governance, and accountability. It does atomic task
checkout and budget enforcement so agents don't double-work or overspend.

**How OpenAcme differs:** Both give you an org chart of agents. Paperclip leans
into **governance and budget control** as first-class features. OpenAcme leans
into **local-first ergonomics and model flexibility** — it's MCP-native, runs on
your existing Claude Pro / ChatGPT subscription via OAuth (no per-token API bill
to experiment), and gives each agent its own isolated browser session and memory
on disk. If budget enforcement across a large agent fleet is your top concern,
look hard at Paperclip. If you want a local, subscription-friendly workforce with
strong MCP and per-agent isolation, that's OpenAcme.

### Multica

[Multica](https://github.com/multica-ai/multica) is a different animal: it's a
**control plane**, not an agent runtime. It turns coding agents you *already use*
— Claude Code, Codex, Copilot CLI, OpenCode, Hermes, Gemini, Cursor Agent, and
more — into managed teammates on a board, with Squads for routing and a cloud
option. Note its license is listed as "Other," not MIT.

**How OpenAcme differs:** Multica orchestrates *external* CLIs; it doesn't run its
own loop. OpenAcme *is* the runtime — the agents, the streaming tool-calls, the
provider integrations, and the dispatcher are all in-house, so behavior is
consistent and there's no dependency on a separate coding CLI being installed and
authed. Pick Multica if you're standardizing a team around several existing
coding agents and want one board over them. Pick OpenAcme if you want a
self-contained workforce you fully own.

### Polsia

[Polsia](https://polsia.com/) is the outlier: a **closed-source** hosted platform
that raised
[$30M at a $250M valuation](https://pulse2.com/polsia-30-million-at-250-million-valuation-raised-for-ai-operations-platform/)
to run business operations autonomously — coding, research, outreach, ads,
support — famously with "one human" and "zero employees." Pricing is reported as
$49/month **plus a 20% revenue share**, and public Trustpilot reviews currently
average around 2.1/5, citing incomplete task execution.

**How OpenAcme differs:** This is the clearest contrast in the list. Polsia is a
vendor cloud you rent and hand a cut of your revenue; your agents, data, and
workflows live on their infrastructure. OpenAcme is **MIT, local-first, and
free** — the agents run on your machine, your data stays on disk, and you bring
your own model. If you want a managed, hands-off service and the revenue-share
model fits, Polsia is an option. If you want ownership, privacy, no recurring
platform fee, and no revenue share, that's the entire reason OpenAcme exists.

## Frameworks vs. platforms: CrewAI, AutoGen, MetaGPT, ChatDev

The four tools above are *applications* — you run them and talk to agents. The
best-known names in "multi-agent AI," though, are **frameworks**: code libraries
you program against to build your own agent system. They're worth knowing because
people often search for them first.

| Project | Stars | License | What it is |
|---|---|---|---|
| [MetaGPT](https://github.com/FoundationAgents/MetaGPT) | ~69k | MIT | "First AI software company" — agents play PM/architect/engineer roles in code |
| [AutoGen](https://github.com/microsoft/autogen) | ~59k | CC-BY-4.0 | Microsoft's agentic framework (now folded into Microsoft Agent Framework) |
| [CrewAI](https://github.com/crewAIInc/crewAI) | ~54k | MIT | Role-playing autonomous agents library; fast to a working crew in code |
| [ChatDev](https://github.com/OpenBMB/ChatDev) | ~33k | Apache-2.0 | Multi-agent software-dev collaboration ("virtual software company") |

**How OpenAcme differs:** These are libraries — you write Python, wire up the
agents, and host the result yourself. OpenAcme is a finished, self-hosted
**product**: a web UI and CLI, persistent agents on disk, a task board, a
scheduler, MCP support, and per-agent browsers and memory — no orchestration code
to write. If you're an engineer who wants to *build* a bespoke agent pipeline in
code, CrewAI or MetaGPT are great toolkits. If you want to *run* a workforce today
without assembling one, that's the gap OpenAcme fills. (Worth noting: AutoGen is
now in maintenance mode after Microsoft merged it into the Microsoft Agent
Framework, so check its status before starting new work on it.)

## So which should you pick?

- **You want one assistant that learns you deeply, everywhere** → Hermes Agent.
- **You want governance and hard budget caps over a large agent fleet** → Paperclip.
- **You want one board over the coding CLIs your team already runs** → Multica.
- **You want a fully managed cloud service and accept a revenue share** → Polsia.
- **You're an engineer who wants to build a custom agent pipeline in code** →
  CrewAI, MetaGPT, or ChatDev.
- **You want to *own* a local-first workforce — MIT, your machine, your model,
  runs on your Claude/ChatGPT subscription, no code to write** → **OpenAcme**.
