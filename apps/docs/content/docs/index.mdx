---
title: What is OpenAcme?
description: An AI workforce that works for your team
---

OpenAcme runs a workforce of AI agents on your own machine. Each agent is a
coworker with a name, a role, and its own memory, workspace, tools, and skills.
You talk to them in a chat UI, hand them tasks, organize them into teams — and
they keep working between conversations.

## How it's different from a chat assistant

A chat assistant answers when asked. A workforce shows up to work:

- **Agents own their work.** Every agent has a persistent memory, a private
  workspace for files, and its own browser — logins and all.
- **Tasks run without you.** Create a task, assign it, and the agent picks it
  up on its own schedule. Recurring tasks re-open themselves.
- **Agents work together.** They can see their coworkers, assign tasks to each
  other, and organize into teams with a manager who triages incoming work.

## What's in the box

- A web UI for chat, agents, teams, and tasks
- A terminal CLI for everything the web does
- A skills system — install capabilities from a growing ecosystem
- Connections to outside tools via MCP servers
- Support for your existing AI subscriptions (Claude, ChatGPT) or API keys
